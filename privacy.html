V2 PARTNER REVIEW · SEPTEMBER 13, 2026

Progress stays in your browser

The game stores completed units, gasoline grades, the resume checkpoint, map availability, and sulfur-recovery best results in browser local storage. It does not associate that progress with a student identity. On a shared device, the next user can see the previous user’s progress.

Use the passport’s Save a copy, Restore a copy, or Clear v2 progress controls. A progress download contains game state, not a name or email address. Unfinished activities restart from their activity checkpoint.

Existing progress and migration

On the same website origin, v2 can copy a compatible earlier Refinery Run save into a separate v2 save. It does not overwrite or delete the original save. Clearing v2 progress leaves an empty v2 record so the original is not imported again automatically.

A different domain, browser, or device has different storage. Progress does not automatically follow you. If browser storage is unavailable, the game works for the current visit but cannot promise to remember progress later.

Certificates

A certificate name is entered only on the certificate page and is used in the page you choose to print. This package does not store or send that name. A saved PDF or paper copy may contain the name you entered; share it only with the intended recipient.

Hosting requests

Your browser requests website files from the server used by the site owner. That hosting provider may process connection information such as IP address, browser details, and request logs. The game has no account database. Hosting configuration and retention practices should be confirmed by the operator before deployment.

Downloads and external links

Classroom resources can be downloaded directly without entering an email. Amazon and LinkedIn links take you to external services governed by their own policies. No external purchases or signups are required to play.

Help and feedback

The feedback page prepares an email in your own mail app. You can review it before sending. Contact is intended for parents, educators, and other adults. Do not include student names or sensitive information in a bug report.

For school and site administrators

These statements describe the supplied v2 files. Adding analytics, forms, advertisements, embeds, or new hosting services changes the data flow and requires an updated review and privacy notice.
