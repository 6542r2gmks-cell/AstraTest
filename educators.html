The Explorer certificate records completion of all 16 activities. It is an educational achievement, not an industrial operating qualification.

Before your first class

Make room for discovery.

  1. Try your school’s devices.Open the game on the same browser and network students will use.
  2. Pick the support level.The print pack suggests coloring for ages 5+ and vocabulary/discussion for ages 8+. Timed game activities may need adult support.
  3. Plan one route first.Allow discussion time. The full 16-unit certificate can span several sessions.
  4. Keep a fixed lesson version.Check the release notes before adopting an update.

Questions teachers ask

Can students use tablets and phones?

The game uses responsive layouts and pointer controls for tapping, holding, and dragging. Test your actual iPad, iPhone, Android, or school laptop before class; browser behavior varies.

Can we pause to discuss something?

Yes. The Pause & help control freezes game time. If the browser is hidden, the game pauses and asks you to resume.

Does progress follow a student between devices?

No. Progress belongs to this browser, not an individual. You can export and restore a progress file, or clear v2 progress before the next learner. No names are included in progress files.

Can I print an Explorer certificate?

After all 16 units are completed, the passport opens a printable certificate. Enter a name only on the certificate page. It is not sent or saved by the game.

Is this v2 approved for my curriculum?

This is a partner-review release. Confirm its version and lesson mapping with your curriculum lead before replacing an approved classroom build.
