Version 2.0.0-rc.2 · September 13, 2026 · Partner-review release

For partner review

This release is ready for technical and classroom evaluation. Its new interface and support controls have not been independently approved by your state or curriculum partner. Complete the included acceptance checklist before replacing an approved build.

What’s new

  • A redesigned website with separate play, educator, book, privacy, and support pages.
  • A visible passport, current-lesson guidance, and suggestions for the next incomplete unit after delivery.
  • Pause/help, explicit resume behavior, and progress export/restore.
  • Device-local v2 saves that preserve the original game’s saved record during migration.
  • Direct activity-pack download and a new printable teacher field guide.
  • A local printable certificate with no external QR-code service or book promotion.

Repairs

  • Certificate controls initialize for new and returning visitors.
  • Grade completion and map unlock are saved immediately.
  • Storage errors allow temporary play rather than stopping the run.
  • Timers and animation callbacks belong to the current activity and stop when it exits.
  • Jet inspection waits for the learner to finish reading instructions.
  • Keyboard activation, interrupted-drag recovery, and optional alternative controls supplement tap/hold/drag.
  • Physics is bundled with the website. No analytics, session replay, advertising tags, or external forms are included.

What stays compatible

The release retains the 16-unit list, product branches, original minigame concepts, current gameplay tuning constants, gasoline component data and recipes, baseline qualification rules, and the original seven-page activity pack. The original lesson engine and scene geometry are adapted behind a new website and game interface.

Gasoline unit credit and the two-grade shipping requirement remain distinct. A new delivery run clears its grade sequence but preserves completed units. The exploration map still unlocks after the first delivery. Optional replay uses existing gasoline grades and SRU modes, adding no certificate requirements.

Documented behavior and wording changes

Help/background pauses and time spent reading instructions no longer consume active game time. Facts wait for the learner instead of dismissing automatically. These changes should be reviewed where a curriculum specifies timing.

Reformer feedback is constructive. Pump-swap text clarifies that the game sequence is not a complete maintenance-isolation procedure. The finale celebrates the completed delivery without repeating the unverified daily-volume statistic. Existing scientific facts remain available for subject-matter review.

Deployment and school checks

The package contains all runtime files, the original activity PDF, local physics, automated checks, a deployment guide, a change register, and a partner acceptance checklist. Use a separate v2 path or test domain first; keep an approved earlier version available until the review is complete.

Review actual school devices, print output, lesson timing, and the curriculum crosswalk. Browser-local progress is not student identity or proof of individual mastery.
